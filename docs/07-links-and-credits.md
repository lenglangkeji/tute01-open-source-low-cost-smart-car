1. 用常规 user-agent 对 `tute01.site` 与 `lenglang.xyz` 上所有可访问页面各抓取一次，并保存原始字节。
2. HTML 快照写入 `../sources/html/`，纯文本提取写入 `../sources/text/`。
3. 下载并保存全部引用图片到 `../assets/`，不做修改。
4. `docs/` 各页为对抓取到的中文内容所做的中英双语整理。

逐页抓取记录见 [`SOURCES.md`](../SOURCES.md)。

### Media attribution

- Project and chassis photographs on `tute01.site` (`che1.jpg`, `che2.jpg`, `che3.jpg`).
- Studio logo, workshop photographs, and WeChat / Douyin contact QR codes on `lenglang.xyz`.
- Competition-coaching gallery images on `lenglang.xyz/consulting.html` (stored under
  `../assets/consulting/`).

All media is stored byte-for-byte as downloaded from the source sites. Images were deliberately
**not** analysed, OCR'd or described.

### How this archive was produced

1. Every reachable page on `tute01.site` and `lenglang.xyz` was fetched once with a normal
   user-agent, and the raw bytes were saved.
2. HTML snapshots were written to `../sources/html/` and a plain-text extraction to
   `../sources/text/`.
3. Every referenced image was downloaded and saved under `../assets/`, without modification.
4. The `docs/` pages were written as bilingual (Chinese/English) digests of the captured text.

See [`SOURCES.md`](../SOURCES.md) for the per-page capture log.
